              SLA RECONCILIATION

              Understand the differences

              Calculated SLA and original Ziwo SLA may use different formulas. Values display two decimals; unrounded differences drive flags, so a tiny flagged gap may display 0.00 pp. No averages of daily SLA percentages.

              Possible explanations for significant gaps

                An alternative formula matching within half a two-decimal display step is a hypothesis to check with Ziwo. These counts cannot establish Ziwo’s configured threshold or internal reporting scope. Your chosen formula and original SLA values are never changed automatically.

                Talk time is not full AHT

                Weighted talk time = Σ(daily average talk seconds × answered queue calls) ÷ Σ(answered queue calls). This report does not contain full handling time. AHT is unavailable here, and the AHT target is not applied to talk time.
